# HTML\_EDITOR // CYBERPUNK

一款赛博朋克风格的在线 HTML 编辑器，支持源码编辑、实时预览、可视化编辑，以及多格式导出与零账号链接分享。

**线上地址：** <https://yoo-moka.github.io/html-editor/>

***

## 功能

### 编辑器

- **源码编辑**：带行号的代码编辑器，支持 Tab 缩进、自动补全括号、回车保持缩进
- **实时预览**：输入内容后即时渲染在右侧预览面板
- **可视编辑模式**（`Ctrl+E`）：直接在渲染结果上点击并修改文字，MutationObserver 自动同步回源码
- **代码格式化**：一键整理 HTML 缩进与排版
- **新建文档**：清空当前内容，回到初始欢迎页

### 布局

- 三栏布局切换：左（源码）、右（预览）、双栏
- 拖拽分隔条自由调整两栏宽度

### 导出

| 格式   | 说明                                                                       |
| ---- | ------------------------------------------------------------------------ |
| HTML | 保存完整 `.html` 文件，可再次编辑                                                    |
| PDF  | 通过 jsPDF + dom-to-image-more 导出，完整还原现代 CSS（oklch、CSS 变量、backdrop-filter） |
| JPG  | 同上，导出为 JPG 截图                                                            |
| URL  | 用 lz-string 将 HTML 压缩进 URL hash，再经 TinyURL 生成短链，**零账号、零服务器**分享           |

### 打开本地文件

支持打开 `.html` `.htm` `.css` `.js` `.txt` `.svg`，可视编辑模式下打开会自动提示 toast。

## 快捷键

| 快捷键      | 功能            |
| -------- | ------------- |
| `Ctrl+E` | 切换可视编辑模式      |
| `Ctrl+S` | 保存更改（可视编辑模式下） |
| `Tab`    | 插入 2 空格缩进     |

***

## 技术实现

- **单文件应用**：所有代码（HTML / CSS / JS）内联在 `HTML编辑器.html` 一个文件中，无需构建工具
- **PDF / JPG 导出**：postMessage 架构，在隐藏 iframe 内注入 dom-to-image-more 截图后传回主页面，完整支持现代 CSS 特性
- **分享链接**：页面加载时检测 `location.hash` 是否以 `#v=` 开头，自动解压还原 HTML 内容
- **短链服务**：使用 tinyurl.com（支持 CORS）；本地 localhost 因 CORS 限制会降级为复制原始长链接
